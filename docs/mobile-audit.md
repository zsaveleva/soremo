# Аудит мобильной вёрстки

Дата: 29.10.2026. Проверены все экраны продукта под тремя ролями (гость, пользователь с пакетом, админ):

- 26 состояний экранов: карта с фильтрами, списком, поиском и нижним листом объекта; отчёты; формы; кабинет; оплата; документы; добавление объекта; админка; витрина `/design`; 404.
- Ширины 360, 390 и 414 px в режиме телефона (касания, `isMobile`), плюс горизонтальная ориентация 844 × 390.
- Повторить: `cd web && node scripts/mobile-audit.mjs 360,390,414` — отчёт `.cache/mobile/report.json` и скриншоты.

## Метод

Автоматическая проверка (`web/scripts/mobile-audit.mjs`) на каждом экране и ширине:

1. Горизонтальный скролл страницы и элементы за краем экрана. Внутри контейнеров с собственной прокруткой выход за край допустим.
2. Зоны нажатия меньше 44 × 44 px (WCAG 2.5.5). Ссылки внутри абзаца — исключение по 2.5.8.
3. Поля ввода со шрифтом меньше 16 px: iOS увеличивает страницу при фокусе на них.
4. Текст меньше 12 px.

Затем — ручной просмотр скриншотов 360 px: перекрытия, обрезанные таблицы, залипающие состояния.

## Оставлено сознательно

- **Ссылки-адреса в таблицах «Мои объекты» и в админке.** Нажимается вся строка таблицы высотой больше 44 px, ссылка внутри — для клавиатуры и открытия в новой вкладке.
- **Ссылки атрибуции OSM внутри раскрытого блока «i».** Их вёрстка принадлежит MapLibre, а требования лицензии OSM важнее размера.
- **Горизонтальная ориентация 844 × 390.** По ширине это десктопная раскладка: боковая панель вместо нижнего листа. Экраны проверены, горизонтального скролла нет.
- **Таблицы админки прокручиваются вбок, а не складываются карточкой.** Модерация — рабочий сценарий для десктопа; на телефоне важнее видеть строку целиком.
